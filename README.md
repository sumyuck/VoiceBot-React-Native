# AI Bot for Voice-Controlled Quick-Commerce App

## Overview

This project integrates an AI bot into a Quick-Commerce app, allowing users to control the app with voice commands. Users can navigate, search for products, and manage their cart using voice, with touch only needed for checkout.

## Features

- **Voice Command Recognition:** Understand and execute commands like “Search for [product]” and “Add [product] to cart”.
- **Navigation:** Navigate the app and view products via voice.
- **Cart Management:** Manage cart items with voice commands.
- **User Feedback:** Provide confirmation and error handling.
- **Checkout:** Complete purchase with touch interaction.

## Setup

1. Clone the repository (you need access): `git clone https://github.com/sumyuck/VoiceBot-React-Native`
2. Install dependencies: `npm install`
3. Start the app: `npm start`
